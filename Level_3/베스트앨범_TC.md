# 베스트앨범 - 자체 테스트케이스

> 참고: 실행 환경에 C++ 컴파일러(libstdc++ 헤더)가 설치되어 있지 않아 실제 컴파일·실행 대신
> `solution` 함수의 로직을 손으로 단계별로 추적(수동 트레이스)하여 검증했습니다.

| # | 입력 | 기대 출력 | 실제 출력 | 결과 |
|---|------|-----------|-----------|------|
| 1 | genres=["classic","pop","classic","classic","pop"], plays=[500,600,150,800,2500] (문제 예제) | [4, 1, 3, 0] | [4, 1, 3, 0] | Pass |
| 2 | genres=["pop","pop","pop"], plays=[10,30,20] (장르 1개뿐) | [1, 2] | [1, 2] | Pass |
| 3 | genres=["a","b","c"], plays=[100,300,200] (모든 곡이 서로 다른 장르) | [1, 2, 0] | [1, 2, 0] | Pass |
| 4 | genres=["rock","rock","jazz"], plays=[50,60,40] (장르 내 곡이 정확히 2개) | [1, 0, 2] | [1, 0, 2] | Pass |
| 5 | genres=["pop","pop","pop","pop"], plays=[100,100,100,500] (재생 횟수 동점 → 인덱스 오름차순 타이브레이크, 4곡 중 상위 2곡만 선택) | [3, 0] | [3, 0] | Pass |
| 6 | genres=["pop"], plays=[1] (입력 길이 1) | [0] | [0] | Pass |
| 7 | genres=["pop","pop","pop"], plays=[2000000000,2000000000,2000000000] (장르 내 재생 횟수 합계가 int 범위(약 21억)를 초과 → long long 필요성 확인) | [0, 1] | [0, 1] | Pass |
